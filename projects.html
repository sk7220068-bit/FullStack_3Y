AI Fashion Recommender & Outfit Upgrader

An end-to-end AI-powered fashion intelligence system that detects clothing items from images, scores outfit compatibility, and suggests occasion-specific upgrades — all backed by computer vision and content-based machine learning.

Java 17 Spring Boot 3.2 Python 3.11 Flask YOLOv8 ResNet50 MongoDB 7.0 React 18 Docker

🧠 How It Works (Full Pipeline)

  1. Upload & Occasion Selection: User uploads outfit image + selects target occasion.
  2. Controller Routing: OutfitController receives request in Spring Boot.
  3. Clothing Detection: OutfitDetectionService calls Python ML service (YOLOv8 detects clothing bounding boxes).
  4. Feature Extraction: FeatureExtractionService passes items to ResNet50 to extract 2048-dim feature vectors per item.
  5. Compatibility Scoring: CompatibilityService computes pairwise style, formality, and vector scores.
  6. Upgrade Engine: OutfitUpgradeEngine evaluates occasion rules to generate itemsToReplace, itemsToAdd, and suggestions.
  7. Recommendation Engine: RecommendationService executes Cosine Similarity against MongoDB outfit dataset.
  8. Persistence & Response: UpgradeResult saved to MongoDB history and returned as JSON to the React frontend.

* Includes graceful ML Fallback (Mock Mode): Operates seamlessly even if the Python service is offline.

🔌 REST API Reference

1. POST /api/upload-outfit

Full pipeline: detect → features → compatibility → upgrade → recommendations.

curl -X POST http://localhost:8080/api/upload-outfit \
  -F "image=@outfit.jpg" \
  -F "occasion=party"

2. POST /api/detect-clothes

Clothing detection only (no upgrade logic).

curl -X POST http://localhost:8080/api/detect-clothes \
  -F "image=@outfit.jpg"

3. POST /api/recommend-outfit

Get outfit recommendations by occasion/style (no image required).

curl -X POST http://localhost:8080/api/recommend-outfit \
  -H "Content-Type: application/json" \
  -d '{"occasion": "party", "style": "smart-casual"}'

4. GET /api/upgrade-history & /api/health

Retrieve the 20 most recent upgrade analyses or perform a system health check.

curl http://localhost:8080/api/upgrade-history
curl http://localhost:8080/api/health

📊 Dataset Schemas

  • outfits.csv (25 records): Contains columns for outfit id, name, style, occasions, items, color_palette, season, formality_score, and feature_vector (64-dim).
  • deepfashion_sample.csv (100 records): Schema-compatible subset of DeepFashion dataset with 13 clothing categories, attribute labels, landmark coordinates, and formality annotations.
